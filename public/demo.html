Documentation / Demo

Compare legacy Script behavior with Function output before launch.

Script Sentinel is audit and evidence tooling for Shopify Plus teams. It does not automatically migrate Scripts, change checkout behavior, replace developer review, or guarantee parity.

1. Legacy Script intake

Inventory the logic being replaced

Paste discount, shipping, or payment Script source so the app can classify the migration-risk surface.

{
  "scriptName": "vip-discount.rb",
  "customizationType": "discount",
  "signals": ["customer-tag", "line-item-sku", "cart-total"]
}
2. Scrubbed fixture

Keep checkout shape, avoid direct identifiers

Fixtures preserve the data shape needed for comparison while avoiding names, emails, phone numbers, full addresses, customer IDs, and free-text customer notes.

{
  "fixtureId": "fixture-vip-001",
  "cartTotal": "148.00",
  "customerTags": ["VIP"],
  "countryCode": "US",
  "postalPrefix": "100",
  "lines": [
    { "sku": "JACKET-XL", "quantity": 1, "price": "148.00" }
  ]
}
3. Expected vs observed

Compare behavior

The audit records expected Script-era output next to observed Function-era output when the Function result is available.

{
  "expectedScriptOutput": {
    "discountTitle": "VIP 15%",
    "discountAmount": "22.20"
  },
  "observedFunctionOutput": {
    "discountTitle": "VIP 10%",
    "discountAmount": "14.80"
  }
}
4. Parity gap

Review migration risk

A parity gap is a review signal for the merchant, agency, or developer team. It is not proof that checkout is broken or safe.

{
  "severity": "review",
  "gap": "discount_amount_changed",
  "expected": "22.20",
  "observed": "14.80",
  "nextStep": "Confirm VIP discount rule before launch"
}
