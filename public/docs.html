Script Sentinel Documentation

Script Sentinel helps Shopify Plus teams audit Scripts-to-Functions migration risk. It compares expected legacy Script behavior with observed Function-era outputs and exports evidence for merchants, developers, or agencies.

For a sample Script intake, scrubbed fixture, parity gap, and PDF evidence flow, see the Script Sentinel demo.

Who It Is For

Script Sentinel is for Shopify Plus merchants and implementation teams that still rely on legacy Shopify Scripts or are validating a migration to Shopify Functions.

Setup

  1. Install Script Sentinel from the Shopify App Store.
  2. Open the app from Shopify Admin and confirm Plus eligibility.
  3. Paste each relevant Script source into the script inventory.
  4. Generate scrubbed cart fixtures from recent order patterns.
  5. Run a Migration Risk Audit and export the PDF evidence.
  6. After migration, use Drift Monitor to compare captured Function outputs against the fixture baseline.

Permissions and Data

Script Sentinel uses read-only Shopify access for shop, order-pattern, and Function discovery surfaces needed for audit evidence. Optional customer fields such as name, email, phone, and full address are not requested for fixtures.

What Gets Scrubbed

Fixtures are designed to preserve checkout-relevant shape while avoiding direct personal identifiers. The audit focuses on discounts, shipping, payment, market, B2B, and related checkout behavior.

What a Parity Gap Means

A parity gap means observed Function-era output did not match the Script-era expectation for a comparable fixture. It is a review signal, not a guarantee that checkout is broken or safe.

What the PDF Contains

The Migration Risk Audit PDF includes a risk summary, per-script findings, fixture coverage, observed parity gaps when available, and open questions for the merchant or developer team.

Billing

One-time audit pricing is $99 for a Single Script Audit and $299 for a Multi-Script Audit during launch pricing. Drift Monitor is $149/month for ongoing regression and parity checks.

What Script Sentinel Does Not Do

Script Sentinel does not automatically migrate Scripts, edit Shopify Functions, change discounts, alter checkout behavior, or guarantee migration readiness.

Uninstall

Uninstall Script Sentinel from Shopify Admin. The app stops new reads and processes Shopify's uninstall webhook. Contact support if retained audit records need review.
